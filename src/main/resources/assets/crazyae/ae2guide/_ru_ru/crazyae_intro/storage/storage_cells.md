# Ячейки хранения

[Ячейки хранения](ae2:items-blocks-machines/storage_cells.md), которые продолжают там, где заканчивается AE2: **от 1 МБ до 128 ГБ**.

## Как скрафтить

1. Сделайте компонент хранения. Первый, на 1 МБ, собирается из компонентов AE2 на 256k, каждый следующий — из компонентов предыдущего уровня.
2. Соедините компонент с корпусом ячейки AE2.
