# Объединитель блоков крафта

Полноценный [процессор крафта](ae2:items-blocks-machines/crafting_cpu_multiblock.md) размером в один блок.
Вместо многоблочной структуры вы **кладёте блоки крафта в его интерфейс**:

- **12 слотов** для блоков сопроцессоров (до 64 в слоте);
- **12 слотов** для хранилищ крафта (до 64 в слоте).

Подходят любые сопроцессоры и хранилища крафта: из AE2, [Crazy AE](crafting_units.md) и других аддонов.
Наведите курсор на крупные иконки слева в окне — появится общее число потоков и байт.

- Занимает один канал, потребляет 1024 AE/т.
- Не объединяется с соседними блоками крафта: поставьте несколько рядом — получите несколько процессоров.
- Пока процессор занят крафтом, менять блоки внутри нельзя. (все предметы, используемые для крафта, пропадут!)
- При разрушении выпадает всё содержимое.

Нужно ещё больше и быстрее? У [квантового процессора](quantum_cpu.md) по 18 слотов каждого вида, и он умеет крафтить с самой максимальной скоростью, что только возможна в игре.
