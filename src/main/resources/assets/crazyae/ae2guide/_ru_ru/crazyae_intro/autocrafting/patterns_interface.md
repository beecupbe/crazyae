# Интерфейс шаблонов

<Row>
  <BlockImage id="patterns_interface" scale="4" />
  <ItemImage id="cable_patterns_interface" scale="4" />
</Row>

[Поставщик шаблонов](ae2:items-blocks-machines/pattern_provider.md) на **72 шаблона** вместо 9.
Работает точно так же, как в AE2: кладёте шаблоны обработки, направляете на машину — сеть отправляет туда ингредиенты.

Есть в виде полного блока и плоской части на кабель; одно превращается в другое на верстаке.
