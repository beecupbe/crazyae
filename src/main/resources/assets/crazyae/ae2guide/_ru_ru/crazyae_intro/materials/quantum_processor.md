# Квантовый процессор (деталь)

<ItemImage id="quantum_processor" scale="4" />

Главный компонент Crazy AE: он нужен для большинства машин и ячеек аддона.
Прессуется в <ItemLink id="ae2:inscriber" /> из [процессоров](ae2:items-blocks-machines/processors.md) AE2 и шарика материи.

Не путайте его с [МЭ Квантовым процессором](../autocrafting/quantum_cpu.md) — тот является блоком для автокрафта.
