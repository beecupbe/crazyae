# Колоризатор

<ItemImage id="colorizer" scale="4" />

Инструмент для оформления интерфейса устройств и предметов из CrazyAE. Открыв его, вы сможете настроить цвет интерфейса и текста Crazy AE на свой вкус.
Меняется только внешний вид окон лично для вас, на работу машин или на других игроков это не влияет.
