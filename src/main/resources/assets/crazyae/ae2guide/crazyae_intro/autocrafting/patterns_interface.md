# ME Patterns Interface

<Row>
  <BlockImage id="patterns_interface" scale="4" />
  <ItemImage id="cable_patterns_interface" scale="4" />
</Row>

A [pattern provider](ae2:items-blocks-machines/pattern_provider.md) with **72 pattern slots** instead of 9.
It works exactly like the AE2 one: put processing patterns in, face it at a machine, and the network sends ingredients there.

Comes as a full block and as a flat cable part. You can convert one into the other in a crafting grid.
