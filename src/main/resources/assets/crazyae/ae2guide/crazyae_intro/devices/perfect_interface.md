# ME Perfect Interface

<Row>
  <BlockImage id="perfect_interface" scale="4" />
  <ItemImage id="cable_perfect_interface" scale="4" />

An [ME Interface](ae2:items-blocks-machines/interface.md) with **36 stocking slots** instead of 9.
Set what it should keep in stock, and it pulls those items from the network (or crafts them).

- Upgrades: <ItemLink id="ae2:fuzzy_card" /> and <ItemLink id="ae2:crafting_card" />.
- Comes as a full block and as a cable part.
