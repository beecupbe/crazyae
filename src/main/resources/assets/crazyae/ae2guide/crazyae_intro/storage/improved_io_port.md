# ME Improved IO Port

<BlockImage id="improved_io_port" scale="4" />

An [IO Port](ae2:items-blocks-machines/io_port.md) with **12 input and 12 output cell slots**.
It empties cells into the network or fills them from it, just much faster.

- <ItemLink id="advanced_speed_card" /> — 1;
- <ItemLink id="stacks_card" /> — up to 3, more items per operation;
- <ItemLink id="ae2:redstone_card" /> — redstone control.
