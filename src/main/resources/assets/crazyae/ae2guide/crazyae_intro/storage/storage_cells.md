# Storage cells

[Storage cells](ae2:items-blocks-machines/storage_cells.md) that continue where AE2 stops: **from 1 MB to 128 GB**.

## How to craft

1. Make a storage component. The first one, 1 MB, is made from AE2 256k components; every next one from components of the previous tier.
2. Combine the component with an AE2 cell housing.
